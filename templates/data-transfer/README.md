# راهنمای فایل‌های ورود داده

هر فایل JSON باید یک آرایه از رکوردهای **فقط یک بخش** باشد. تصاویر را ابتدا از بخش «رسانه‌ها» به‌صورت گروهی بارگذاری کنید و سپس نام دقیق فایل را در JSON بنویسید؛ برای نمونه `nilper-chair-main.webp`.

در صفحه همان بخش، از منوی فهرست گزینه «ورود» را بزنید و یکی از روش‌ها را انتخاب کنید:

- «فقط ایجاد» برای رکوردهای کاملاً جدید؛
- «فقط به‌روزرسانی» برای تغییر رکوردهای موجود؛
- «ایجاد یا به‌روزرسانی» برای ترکیب این دو حالت.

برای به‌روزرسانی یا ایجاد/به‌روزرسانی، کلید تطبیق هر بخش چنین است. اگر مقدار پیش‌فرض `id` را تغییر ندهید، نیلپر در بخش‌هایی که کلید پایدار دارند آن را خودکار به مقدار جدول زیر تبدیل می‌کند:

| بخش | کلید تطبیق |
| --- | --- |
| برند، دسته‌بندی، سری محصول، محصول، دسته‌بندی مجله، مطلب و پروژه | `slug` |
| گروه پیکربندی | `key` |
| نوع گونه | `name` |
| گونه محصول | `nilperCode` |
| گزینه پیکربندی و گزینه گونه | `id`؛ خروجی همان سایت این مقدار را نگه می‌دارد و برای افزودن رکورد جدید باید از حالت «فقط ایجاد» و فایل بدون `id` استفاده کنید |

مقادیر ارتباطی در این نمونه‌ها قابل‌حمل‌اند: محصول با `slug`، گونه با `nilperCode`، گروه پیکربندی با `key`، نوع گونه با `name` و تصویر با `filename` ارجاع داده می‌شود. وضعیت `_status` برای محصولات، گونه‌ها و مطالب حفظ می‌شود.

ترتیب معمول ورود داده: رسانه‌ها، برندها و دسته‌بندی‌ها، سری‌ها و گروه‌ها، گزینه‌ها و انواع گونه، محصولات، گونه‌ها، مطالب و پروژه‌ها.
